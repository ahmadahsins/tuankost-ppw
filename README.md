# TuanKost

TuanKost adalah aplikasi Laravel sederhana untuk menampilkan informasi kamar kos.

## Menjalankan aplikasi

1. Atur koneksi MySQL pada file `.env` dan gunakan database `tuankost-db`.
2. Jalankan `php artisan migrate`.
3. Jalankan `php artisan serve`.
4. Buka alamat yang ditampilkan oleh Artisan pada browser.

Tahap ini mencakup route, Blade, controller, migration, dan Query Builder.
